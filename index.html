Vertical FX list

FX list

The basics

Open, bypass, reorder, and group FX directly in the vertical list—no window juggling required.

: Open/Close FX
Alt + : Delete FX
Shift + : Bypass FX
Ctrl + Shift + : Toggle FX Online/Offline
Alt + : Rename FX

FX Linking

Link FX parameters between different instances of the same plugin. Good for dubbing and harmonies etc.

Ctrl + Drag to initiate.

FX marquee selection

Select multiple FX at once using marquee selection. When FXs are marquee selected, you can perform actions like tweaking wet/dry, bypass, move, and copy on multiple FXs simultaneously.

: Marquee select
Shift + : Add to marquee selection

Automation icon

An automation icon appears in the FX button when there's automation for the FX's parameters, making it easy to see which FXs have automation at a glance.

: Toggle show/hide envelope
Shift + : Bypass envelope
Alt + : Remove envelope

Containers and Parallel

REAPER's native containers and parallel processing made intuitive. The GUI clearly visualizes your signal flow with automatically color-coded containers, making it easy to see parallel paths and nested FX chains at a glance.

Loudness matching

Automatically match the perceived loudness of your signal before and after FX processing. FX within the orange rectangle are analyzed for loudness changes. Drag the orange boundary lines to adjust which FX are included. After playback begins, loudness matching typically activates within a few seconds. Click the gain readout to lock the current gain adjustment, or drag it to manually set the level change.

Note: This feature requires the free ABLevelMatchingJSFX plugin by TB Pro Audio. Download it here.

Sends management

Master your signal flow with a complete suite of send tools.

Basics

Create sends by dragging between tracks, then adjust volume and routing directly in the FX list.

Alt + : Delete send
Shift + : Mute send
Ctrl + : Create Send Volume Envelope

Favorites

Save and quickly access your most-used sends and FX chains.

Hide Buses

Keep your TCP clean by hiding sends, but access them instantly via the popup controls.

Channel shortcuts

Press 1-8 while dragging to route to specific channels instantly.

1 - 8 : Set destination channels
Alt + 1 - 8 : Set source channels

Pane Width

Set the sends pane width individually for each track to match your workflow. Hide the sends pane entirely for tracks that don't use sends, keeping your interface clean and organized.

Shift + : Adjust send pane width for track

Send FX

The Send FX feature creates a container that automatically routes to a new pair of unused channels. Add FXs into the container to process the signal going into the buses without affecting the direct out signal.

Marquee sends

Select multiple sends at once using marquee selection. When sends are marquee selected, you can perform actions on multiple sends simultaneously, making bulk adjustments quick and efficient.

: Marquee select sends
Shift + : Add to marquee selection

Hide Folder Tracks, but keep them accessible

Hidden parent tracks will be shown as buttons in FX list, right clicking on them will unhide them, while left clicking shows a popup that let's you adjust all essential controls.

Installation

  1. Download installer

    Download the script file, Open the action list in Reaper, and click 'New Action...' , and 'Load ReaScript...' , and load the 'Cool Reaper Script Installer.Lua' you just downloaded.

  2. Install

    Click 'Install' in the installer script.

  3. Run

    Go back to action list, search for 'CRS_vertical fx list', and run.

Requirements

  • REAPER 6.0+ (tested on 6.x / 7.x)
  • macOS 12+ or Windows 10+
  • ReaImGui 0.9.3+ (bundled in script)
