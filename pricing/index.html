Set up FX Devices

  1. 1

    Download the Script Manager

    The free installer that installs and updates your scripts.

    Download the Script Manager
  2. 2

    Load and run it in REAPER

    Open the Actions list, click New action then Load ReaScript, pick the Cool Reaper Script Manager.lua you downloaded and run it. It moves itself into REAPER, so the downloaded file disappears.

  3. 3

    Sign in and install

    Next to FX Devices, click Sign in with browser. The activation page opens with a code. Sign in with the email your key was sent to, using Google, a password or Email me a sign-in link. Check that the code matches the one in REAPER, click Activate, then click Install in the Script Manager.

  4. 4

    Run FX Devices

    Search the Actions list for BryanChi_FX Devices and run it. It opens already activated. Updates live under Scripts and updates in FX Devices' settings, so you won't need the Script Manager file again.
