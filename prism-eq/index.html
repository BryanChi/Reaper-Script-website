Prism EQ

A 16-band EQ that also listens. Any band can turn dynamic, react per frequency bin, saturate its own range, or work only on the mid or the sides. It's free.

Get Prism EQ What it does

02 Features

Every band does more

Double-click to add a band, drag to move it, scroll for Q. Everything else lives in the band panel underneath the display.

01

Dynamic bands

A band can cut or boost only when its range gets loud. Tame harsh hats or a boomy note without dulling the rest of the mix.

02

Spectral mode

Dynamics run per FFT bin inside the band, so only the resonances that poke out get pulled down.

03

Auto threshold

The threshold follows the band's own long-term level. Auto attack and release follow the material too.

04

Band saturation

Tape, Tube, Transistor, Soft Clip, Hard Clip, Diode, Fold and Bitcrush on the band's own range. Oversampled and level-matched.

05

Stereo placement

Put any band on Stereo, Left, Right, Mid or Side. Add air to the sides, or tighten the low end in the middle.

06

Zero latency or linear phase

Analog-matched filters with no cramping near Nyquist, or a linear-phase mode when phase matters. Plus Clean, Subtle and Warm character.

03 Install

Three steps

  1. 1

    Download the Script Manager

    The free Cool Reaper Script Manager installs Prism EQ and keeps it up to date.

    Download the Script Manager

  2. 2

    Run it in REAPER

    Open the Actions list, click New action then Load ReaScript, pick the Cool Reaper Script Manager.lua you downloaded, and run it. Under Plugins, click Install next to Prism EQ. No sign-in needed. Then restart REAPER so it finds the new plugin.

  3. 3

    Add it to a track

    Open the FX browser and search for Prism. To update it later, run the Script Manager again from the Actions list.
